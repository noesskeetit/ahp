# Согласованные исключения для прототипа

## Текущий объём приёмки: AHP, личный Dot и два SDK

3 ноября 2026 пользователь уточнил: Dot является личным агентом; текущая работа и приёмка сосредоточены на AHP для исследований SDK/harnesses. Новые функции Agent Space, включая общий чат и приглашения, отложены и не блокируют AHP. Backend — Go; SDK обязательны для Python и Go с одинаковой семантикой публичных платформенных операций. Проверки доступа разных пользователей и tenants сохраняются.

Подробная граница и правила матрицы: [принятое решение](decisions/2026-11-03-ahp-first-personal-dot.md). Это изменение требований/приоритета, а не доказательство выполнения исходного PDF целиком.

## Реальные microVM

По прямому решению заказчика Compute использует явно обозначенный MOCK физических microVM. Lifecycle, полномочия, квоты, команды и пользовательские сценарии по-прежнему требуют реализации и проверки. Реальная изоляция гостя и производительность гипервизоров этим режимом не подтверждаются.

## Внешние Cloud IAM и KMS/BYOK

2 ноября 2026 заказчик после объяснения назначения этих сервисов разрешил использовать mocks или синтетический контур: «ну можем чисто тоже на моках сделать, либо на синтетических».

Для PoC выбран явно обозначенный синтетический профиль. В нём проверяются разрешения по ресурсам, отказы чужому субъекту, отзыв и обмен токенов на тестовых пользователях/политиках; ключи шифрования тестовые и локальные. Этот режим не является приёмкой настоящих Cloud.ru IAM/KMS/BYOK. Подключение реальных облачных служб не блокирует согласованную приёмку прототипа.

Из этого исключения не следует разрешение безусловно разрешать доступ, хранить реальные credentials в Git или выдавать тестовый режим за production. Прочие требования документа и проверки поведения продолжают действовать.
