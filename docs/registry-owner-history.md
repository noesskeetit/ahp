# Registry owner history

`GetInvokedTask` has a separate read-only human path. A verified browser JWT must arrive over an approved exchanger deployment's mTLS certificate. Identity checks the live browser session and current `registry` permission. The authenticated tenant/subject, historical Identity task/context and Registry's immutable task pin select the State record. No task grant is issued or renewed. Task credentials retain the original-parent check of the runtime observation path.

An operator enables the supported reader with `AHP_REGISTRY_STATE_OBSERVERS_FILE`, a JSON array of `{ "image": "repository@sha256:…", "protocol": "ahp-agent-state-v1" }`. This declaration is specific to an immutable image. It describes the existing `cmd/ahp-agent` result format: a State run with the Identity task/context, payload digest/config revision, and terminal checkpoint in the run-ID namespace with matching image/digest/config revision and an `output` part. The reader returns the saved A2A-compatible task result without contacting the container, including after execution grant expiry.

Other harness formats and `own_tables` manifests are explicitly unsupported. A completed State run without the expected output cannot become an empty completed response. The declaration does not change the installation, immutable runtime binding, or permissions for execution. Human JWTs reach only the central Registry read adapter, never an agent runtime.

The historical Identity context's accumulated labels also gate this private output sink. Every read merges the grant snapshot with the current monotonic context journal; labels added by a later task in that context therefore restrict older results too. A missing journal fails closed. Secret/external taints and a different subject restriction are denied by the existing `labels.CheckWrite` policy. Workspace-only restricted results fail closed because this reader has no live workspace membership adapter; operator image attestation does not grant workspace access. This is an explicit support limit, not permission to erase labels or mint an unlabelled replacement grant.

`TestRegistryOwnerHistoryHTTPReauthenticationAndMachineBoundary` exercises real PostgreSQL and HTTPS with a verified client certificate: original machine parent, unrelated/expired parent denial, fresh human login and repeated read, revoked session, another subject, missing permission, unapproved edge, undeclared runtime protocol, and private-sink label restrictions. Its State output, evaluation content, and runtime endpoint are test fixtures; this test does not claim LLM execution. The separate live browser acceptance must compare the rendered saved output hash with the original invocation after a new login and reload.
