# Какой счётчик приёмочный (одна строка)

Приёмку Go-прогонов определяет `scripts/skip-verdict.mjs`; `private/pdf-closure-20261102/run-tests.py`, `tools/gate-live-env-wip/gate-leg-expect.sh` и счётчик внутри `go test` у Heisenberg'а — вспомогательные, их показания не являются вердиктом приёмки.

- Владелец решения о том, кто из счётчиков объявляется путём: прораб (объявление в форуме).
- `scripts/skip-verdict.mjs` — счётчик по всем уровням (родитель и подтесты), вердикт полем, коды выхода 0/1/2/3; до объявления прораба он остаётся измерителем, а не путём.
- `run-tests.py` (untracked scratch, только rc) — не приёмочный по определению: rc не различает измеренный прогон и прогон из одних пропусков.
- `tools/gate-live-env-wip/gate-leg-expect.sh` — проверка ожидания по отдельной ноге, не вердикт.
- Счётчик Go-полосы (внутри `go test` у Heisenberg'а) — самопроверка полосы, не внешняя приёмка.
