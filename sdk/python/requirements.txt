#

# checkpoints, pending writes, KV CAS). They are required only for the
# LangGraph adapters:

#   * ahp_state/store.py         -> AHPStore            (langgraph.store.*)
# ...and for the adapter test-suite (tests/), which builds a real StateGraph.
#
# ahp_state/requirements.txt holds the minimal sub-set for the adapters alone;
# this file is the full set used by tests/state/run_acceptance.sh.
# Native langgraph.checkpoint.postgres (PostgresSaver) is intentionally NOT a
# dependency: state MUST flow through the AHP State HTTP API.
